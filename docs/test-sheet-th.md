# ใบเทส RoomRun (ไม้จริง)

ลิงก์เกม: https://rurtt.github.io/RoomRun/

## เตรียม
- คอม: เปิดลิงก์ใน Chrome หรือ Edge (ต้องมี Bluetooth / ดองเกิล)
- มือถือ Android: Chrome / iPhone: แอป Bluefy
- เปิดไม้ทั้งสองอัน กด "เลือกจอย" ที่ L แล้วที่ R ให้ขึ้น 2/2
- เกมอัปเดตเองเมื่อ Pong push ใหม่ ถ้าไม่เห็นของใหม่ให้กด Ctrl+Shift+R

## เทส (จด ✅ / ❌ + เหตุผลสั้นๆ)

ไม้ + การเชื่อมต่อ
1. ไม้สองอันต่อพร้อมกันได้ไหม เล่นจนจบรอบโดยไม่หลุด
2. ปุ่มเล็ก = เริ่มเกม (หน้าแรก) และเริ่มใหม่ (ตอนโดนจับ) ใช้ได้ไหม กลางเกมกดแล้วต้องไม่มีอะไรเกิด
3. ปิดไม้หนึ่งอันกลางเกม: เกมหยุด ขึ้น "จอย...หลุด กำลังต่อใหม่…" ไหม เปิดไม้ใหม่แล้วเล่นต่อเองได้ไหม (ภายในไม่กี่วินาที)

ช่วงนาทีแรก
4. เล่น 3 รอบ ฝูงหมามาราว 20 วิ: สนุก/ตื่นเต้น หรือรู้สึกไม่แฟร์
5. หลบเลนแบบเฉียดๆ ตั้งใจช้า: ขึ้น "เฉียด!" ไหม หลบง่ายๆ ต้องไม่ขึ้น
6. กระโดดข้ามหมา/โอ่งช้าๆ: ขึ้น "เฉียด!" ไหม กระโดดเร็วไป ต้องไม่ขึ้น
7. สั่นตอน "เฉียด!" ต่างจากสั่นตอนชนพอไหม

ตารางอันดับ
8. ก่อนเริ่ม กด Shift+L ล้างตาราง
9. โดนจับแล้วติด top 5: ปุ่มใหญ่ = เลื่อนช่องเหลือง, ปุ่มเล็ก = เลือก, ปุ่มเล็กอีกที = เริ่มใหม่
10. รีโหลดหน้าเว็บ: ตารางยังอยู่ไหม

## ส่งกลับให้ Pong
- อุปกรณ์ที่ใช้ (คอม/มือถือ รุ่นอะไร, browser)
- ข้อที่ ❌ + เกิดอะไรขึ้น ถ้าถ่ายคลิปได้ยิ่งดี
- อะไรที่รู้สึกแปลก/ไม่สนุก บอกได้หมด
